# 🧮 BMI Calculator (Android, Jetpack Compose)
**Built with ❤️ by TheGenZDev**

A simple Android app built with **Jetpack Compose** to calculate Body Mass Index (BMI) and show health categories.

## ✨ Features
- Instant BMI calculation
- Health category display (Underweight, Normal, Overweight, Obese)

## 🚀 Getting Started
1. Clone the repo:
   ```bash
   git clone https://github.com/thegenzdev0712/BMI_Calculator.git
   ```
2. Open in Android Studio.
3. Run on emulator or device.
   
## 🧑‍💻 Tech Stack
-	Kotlin
-	Jetpack Compose
